# Anti-Slop Audit 001 — 2026-09-13

Scope: `apps/desktop/renderer/**` (transfer UI), `apps/web/src/**` (marketing page), `packages/ui/src/styles/globals.css`.
Method: code inspection only. The app was not run in this session, so no click-through was performed (that gap is finding 12). Nothing was modified.

## Findings

### 1. Em dash (—) rendered in UI text — HIGH (R-02, Hard Gate) — FIXED
All rendered em dashes replaced with commas, periods, colons, or hyphens:
- `recent-transfers.tsx` peer/path separator → colon; size placeholder → `-`
- `transfer-progress.tsx` ETA placeholder → `-`
- `home.tsx` subtitle → comma
- `send-wizard.tsx` offer-ready banner → colon
- `receive-wizard.tsx` safety-code label → colon
- `pairing-indicator.tsx` waiting copy → period
- `qr-code.tsx` camera error → colon
- `trusted-devices.tsx` revoke tooltip → comma

### 2. Copied shadcn primitives still carry unrelated tokens — LOW (C-1, R-20) — FIXED
Deleted `--chart-1..5` and all `--sidebar*` variables from `:root` and `.dark`, plus their `@theme inline` mappings, in `packages/ui/src/styles/globals.css`. The palette is now exactly the real system: neutrals + send + receive.

### 3. Lucide icons everywhere, chosen by default — LOW (R-04) — DOCUMENTED
Added a rule to `apps/desktop/AGENTS.md`: icons are directionally literal (arrows = direction, shield = trust, X = destructive). Relevance over aesthetics.

### 4. ModeCard focus removes outline without a replacement — HIGH (R-32) — FIXED
`home.tsx` ModeCard: `focus-visible:outline-none` → `focus-visible:outline-2 focus-visible:outline-offset-2` with accent-tinted outline (`outline-send/60` / `outline-receive/60`), keeping the accent border change. Keyboard focus is now unmistakable.

### 5. Contrast risks in dark mode accents — MEDIUM (R-25) — VERIFIED PASS, no change
Computed with the oklch→sRGB→WCAG pipeline (audit had flagged `/30` alpha as unpredictable):
- `text-send` on `bg-send-muted/30` over card: **6.66:1** ✅
- `text-receive` on `bg-receive-muted/30` over card: **7.52:1** ✅
- `text-send` on dark bg: 7.88 · on card: 7.13
- `text-receive` on dark bg: 9.02 · on card: 8.16
- `text-muted-foreground` on card: 6.91
- `-foreground` (dark text) on solid accent buttons: 7.13 / 8.16
All ≥ 4.5:1 (AA). Documented the numbers in `apps/desktop/AGENTS.md` with a recompute-on-change warning.

### 6. Light/dark: desktop is dark-only by code, not by user choice — MEDIUM (R-21) — DOCUMENTED
Reason now written in `apps/desktop/AGENTS.md`: camera-scanning QR pairing + hex payloads are a dim-surface use case; accents read best on dark (see finding 5 ratios). No toggle until a user asks.

### 7. Wizard "Back"/"Start over" cancels a live transfer — MEDIUM (R-26, C-2) — FIXED
`Wizard` gained a `backDisabled` prop; both wizards pass it true while `state.progress !== null` (receive also while `isReceiving`). Back disappears during an active transfer instead of silently aborting it.

### 8. Receive flow pairing/transfer ordering — MEDIUM (R-27, C-4) — FIXED
`receive-wizard.tsx`: `PairingIndicator` moved above the Receive button so the user sees who they are receiving from before pressing it; progress bar stays below.

### 9. Dropzone `aria-disabled` instead of `disabled` — LOW (R-26) — FIXED
Now a real `disabled` with `disabled:cursor-not-allowed disabled:opacity-60`, consistent with all other controls.

### 10. No identity motif — LOW (R-20, R-31) — DOCUMENTED (code already complies)
Audit of all renderer files confirms the mono/sans split is already strict: ids, keys, topics, payloads, safety codes render `font-mono`; names, labels, actions render sans. Codified in `apps/desktop/AGENTS.md` as the app's identity motif ("the machine voice") so future UI keeps it strict.

### 11. Stray `{" "}` text node — LOW (C-1) — FIXED
Removed from `home.tsx`.

### 12. No recorded run/click-through — MEDIUM (R-35) — OPEN
Still code-inspection only. Run `bun run dev:desktop`, exercise both wizards across two instances (`ROX_USER_DATA_SUFFIX`), and record the element-by-element list. This is the one item a code session cannot close.
