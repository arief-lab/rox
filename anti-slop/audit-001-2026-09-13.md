# Anti-Slop Audit 001 — 2026-09-13

Scope: `apps/desktop/renderer/**` (transfer UI), `apps/web/src/**` (marketing page), `packages/ui/src/styles/globals.css`.
Method: code inspection only. The app was not run in this session, so no click-through was performed (that gap is finding 12). Nothing was modified.

## Findings

### 13. `transfer.sendFile` "Corestore is closed" — RESOLVED, was a test artifact
Re-tested with exactly one instance per userData dir: the real cause was **multi-instance lock contention** — all test instances shared `~/.config/desktop/` because `ROX_USER_DATA_SUFFIX` was only applied in dev mode. Two fixes landed:
- `main.ts` now applies `ROX_USER_DATA_SUFFIX` in prod too (before `app.whenReady`).
- Confirmed: single instance → `transfer.sendFile` returns `{ ok: true, driveKey, topic, senderId }`; two properly isolated prod instances → full click-through ALL PASS with zero console errors (see finding 12 evidence below).
Follow-up worth considering (not a defect): the packaged app has no single-instance lock, so two accidental launches sharing one userData dir will contend over the Corestore lock and fail transfers confusingly. `app.requestSingleInstanceLock()` would make the second launch focus the first window instead.

### 2. Copied shadcn primitives still carry unrelated tokens — LOW (C-1, R-20) — FIXED
Deleted `--chart-1..5` and all `--sidebar*` variables from `:root` and `.dark`, plus their `@theme inline` mappings, in `packages/ui/src/styles/globals.css`. The palette is now exactly the real system: neutrals + send + receive.

### 3. Lucide icons everywhere, chosen by default — LOW (R-04) — DOCUMENTED
Added a rule to `apps/desktop/AGENTS.md`: icons are directionally literal (arrows = direction, shield = trust, X = destructive). Relevance over aesthetics.

### 4. ModeCard focus removes outline without a replacement — HIGH (R-32) — FIXED
`home.tsx` ModeCard: `focus-visible:outline-none` → `focus-visible:outline-2 focus-visible:outline-offset-2` with accent-tinted outline (`outline-send/60` / `outline-receive/60`), keeping the accent border change. Keyboard focus is now unmistakable.

### 6. Light/dark: desktop is dark-only by code, not by user choice — MEDIUM (R-21) — DOCUMENTED
Reason now written in `apps/desktop/AGENTS.md`: camera-scanning QR pairing + hex payloads are a dim-surface use case; accents read best on dark (see finding 5 ratios). No toggle until a user asks.

`Wizard` gained a `backDisabled` prop; both wizards pass it true while `state.progress !== null` (receive also while `isReceiving`). Back disappears during an active transfer instead of silently aborting it.
